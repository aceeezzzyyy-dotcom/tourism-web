ORMIN TARA — TOURISM WEBSITE PROJECT (UPDATED)
==============================================
Open index.html in a browser to preview the website.

Pages:
- index.html: Home and tourism marketing call-to-action
- about.html: Background, mission, vision, location, target market, tourism value
- places.html: Destination cards, filters, and practical travel details
- packages.html: Three sample tour packages and itineraries
- gallery.html: Eight illustrative images and captions
- guide.html: Weather, packing, clothing, safety, accessibility, emergency reminders, map, FAQ, and disclaimer
- plan.html: Interactive trip-preparation checklist and progress indicator
- contact.html: Inquiry form that prepares a message in the visitor's email app
- style.css: Responsive styles
- main.js: Mobile navigation, destination filters, checklist progress, and inquiry form

Important before submission:
1. Contact details are fictional placeholders. Replace hello@ormintara.example and the sample telephone number with details approved by your instructor or clearly retain them as fictional project data. The .example email cannot receive messages.
2. The form uses mailto and does not store/send information through a server. To demonstrate actual online submissions, connect an instructor-approved form backend before publishing.
3. Tour package costs are illustrative estimates, not verified supplier quotes. Verify all travel information, schedules, access, fees, emergency contacts, and local rules with current official sources.
4. Gallery photos are illustrative and may not depict the exact named destinations. Replace them with your own photos or properly licensed images and add the required credits. External images and Google Maps require an internet connection.
5. Check all pages, navigation links, buttons, form behavior, mobile layout, and image loading.
6. Publish the website (for example, using GitHub Pages) before generating the final QR code. The QR code must point to the published website URL; it cannot be finalized from local files alone.
7. Review the code and content so you can explain your work during evaluation.

To publish on GitHub Pages:
1. Upload all project files to the same repository.
2. Keep index.html in the published root.
3. Enable GitHub Pages in repository Settings > Pages.
4. Open the published URL on desktop and phone; test all pages.
5. Generate a QR code for the final published URL and upload it to Google Classroom as instructed.
